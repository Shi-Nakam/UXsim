purpose: FCFS completion check under research candidate road conditions (all 168 links 200 m, 60 km/h free flow, jam density 0.2 veh/m) with 3000 vehicles evenly spaced over departure T=0..999 (nominal 3 veh/timestep). One exec_simulation observes T=0..4999. Checks whether all vehicles complete normally by T=4999, records completion timing and T=4999 link occupancy. Prior information for future 3000-vehicle TVT-MP trial design (evaluation end, TSIZE, observation horizon). Not a TVT-MP benchmark comparison.
This trial checks whether all vehicles complete normally by T=4999, records non-completion if any vehicles remain, and does not require successful full completion in order to write diagnostic outputs.
Departure-end traffic snapshot at T=999 is stored by the existing departure-999 evaluation pretrial. This completion check does not re-fetch T=999 link or vehicle snapshots, does not split exec_simulation, and does not read pretrial output files at runtime.
world.exec_simulation() is called exactly once. UXsim runs T=0..4999 even if all vehicles finish earlier; World.T after simulation is 5000.
Departure times are evenly spaced from T=0 through T=999 for 3000 vehicles. Nominal average injection rate over the 1000-timestep window (T=0..999) is 3.0 veh/timestep (3000 / 1000). If the same total rate were split evenly across the 24 external OD nodes, the nominal average would be 0.125 veh/timestep per node. Actual OD assignment follows random OD sampling and is not guaranteed to be uniform per external OD node.
Same demand and road conditions as the departure T=999 FCFS pretrial (3000 vehicles, departure T=0..999, all links 200 m, 60 km/h). That pretrial stops at T=999; this completion check runs to T=4999.
All 168 directed links are 200 m. Free-flow speed is 60 km/h (~16.667 m/s). Jam density is 0.2 veh/m. capacity_in and capacity_out are not passed to addLink; UXsim default automatic values apply. No additional 1500 veh/h (0.4167 veh/s) boundary capacity is configured.
